# ManFound legal source documents

These Markdown files are publication-ready source copies of the legal and safety
documents shown in the app. Their shared metadata is maintained in
`src/legal/policies.ts`.

Before publishing, replace every bracketed placeholder:

- `[LEGAL ENTITY NAME]`
- `[BUSINESS ADDRESS]`
- `[GOVERNING LAW AND COURTS]`
- `[SUPPORT EMAIL]`
- `[PRIVACY CONTACT EMAIL]`
- `[CHILD SAFETY CONTACT EMAIL]`
- `[PUBLIC WEBSITE URL]`

The Privacy Policy and an account-deletion help page must be hosted at stable,
publicly accessible web URLs for app-store submission. The current in-app
Delete Account page is informational only; it does not delete an account.
