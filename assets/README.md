# ManFound logo asset

Place the production logo at:

`assets/manfound-logo.png`

Recommended source:

- PNG format
- 1024 × 1024 pixels
- Square canvas
- Opaque `#0F241E` background for iOS compatibility
- Logo centered with generous safe space so Android adaptive-icon masks do not crop it
- No small text or details near the canvas edges

Expo uses this one file for the general app icon, iOS icon, Android adaptive-icon
foreground, splash screen, and web favicon.
